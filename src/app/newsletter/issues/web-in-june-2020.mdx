Taking a month off from bragging about remote work, I would like to shine the spotlight an amazing JavaScript tool:

- [esbuild](https://github.com/evanw/esbuild) - A JavaScript bundler written in [Go](https://golang.org/). ESBuild is currently used in tools like [vite](https://github.com/vitejs/vite) and [snowpack](https://www.snowpack.dev/). It is reported to be a 100x faster than existing tools 😱. Are we ready to accept JS tools that are written in other languages faster than JS? What does it mean for other tools in the ecosystem?

[Hey](https://hey.com/) A new email client from makers of Basecamp launched this month, with focus on privacy. Putting the actual use case and marketing aside, Hey is build with very little JavaScript and 100% HTML over the wire, here's a [Twitter thread](https://twitter.com/sstephenson/status/1272608076433166336). Some people like Rich Harris (who created Svelte) [think that](https://twitter.com/Rich_Harris/status/1276671956092403712) interface for apps like Github and Hey is proof why we should use modern web javascript frameworks.
