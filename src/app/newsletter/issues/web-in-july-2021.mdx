# In the Spotlight 🔦

`npm audit` and github's dependabot alerts don't work. This isn't news, if you have used any of these features, you already know. If you are a frontend developer, these are especially useless. The vulnerabilities mentioned are often in the build systems or worse, build systems of your dependencies. Dan explains how `npm audit` is broken on his new blog post.

[https://overreacted.io/npm-audit-broken-by-design/](https://overreacted.io/npm-audit-broken-by-design/)
