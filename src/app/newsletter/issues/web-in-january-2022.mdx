## Releases

- [Firefox Android](https://blog.mozilla.org/en/mozilla/new-privacy-protection-for-firefox-focus-on-android/) - comes with Total Cookie Protection build in.
- [Parcel CSS](https://github.com/parcel-bundler/parcel-css) - Parcel Bundler now has a CSS parser, transformer and minifier completely written in Rust.
- [Class Sorting Tailwind Classes with Prettier](https://tailwindcss.com/blog/automatic-class-sorting-with-prettier) - After many extensions and plugins, tailwind now has official class sorting with Prettier and it sorts to a default no config recommended order.
- [MacOS 12.3](https://developer.apple.com/documentation/macos-release-notes/macos-12_3-release-notes#Python) - This release is important because _Python 2.7 was removed from macOS in this update. Developers should use Python 3 or an alternative language instead._
- [Topics API from Google](https://blog.google/products/chrome/get-know-new-topics-api-privacy-sandbox/) - Because everyone is isolating third party cookies, advertisers need a different API to communicate with users. Google is the company to lead the pack coming up with FloC API which we had discussed on a previous newsletter. Now it is being replaced by the new Topics API - the gist being that every browser saves a list of topics relevant to the user which is then shared with the advertisers.
- [Private Network Access - Introducing Preflights](https://developer.chrome.com/blog/private-network-access-preflight/) - Chrome is deprecating direct access to private network endpoints from public websites as part of the Private Network Access (PNA) specification. Preflight request will carry a new header, Access-Control-Request-Private-Network: true, and the response to it must carry a corresponding header, Access-Control-Allow-Private-Network: true
