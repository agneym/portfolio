Hey October!

October means it's time for [Hacktoberfest](https://hacktoberfest.com/). Over the years, there has been very different public opinion about what the fest and the month means for everyone and there are still apprehensions. If you aren't familiar, the fest is about celebrating open source and encouraging more people to directly contribute and support open source projects.

This year, Hacktoberfest focuses on brining in non code interactions with open source projects b bringing chores like design, testing, documentation to the forefront.

---

## Releases

### Browsers

- [Firefox 105](https://developer.mozilla.org/en-US/docs/Mozilla/Firefox/Releases/105) ships with Offscreen Canvas API (just Safari to follow up now) and Intl improvements.
- [Chrome 106](https://developer.chrome.com/blog/new-in-chrome-106/) brings new Intl APIs for currency and number formatting. There is a [Popup API](https://developer.chrome.com/blog/pop-ups-theyre-making-a-resurgence/) on origin trial now which will make creating modals much easier.
- [Safari 16](https://developer.apple.com/documentation/safari-release-notes/safari-16-release-notes) adds support for container queries and animatable grids. On the JavaScript front are form improvements like `requestSubmit` and `showPicker`.
- Microsoft Edge Canary is shipping with it's own VPN that Microsoft calls [_Microsoft Edge Secure Network_](<(https://techcommunity.microsoft.com/t5/articles/introducing-microsoft-edge-secure-network/m-p/3367243)>). Microsoft has partnered with Cloudflare to offer the VPN which connects users to nearest Cloudflare network (no geolocation hacks) and hide their IP address. However, to save bandwidth these might be turned off on network heavy operations like gaming or streaming.

### [Next.js 12.3](https://nextjs.org/blog/next-12-3)

Next.js 12.3 is the beginning for new layout components for Next.js. From just file system based routing, Next.js is introducing more complex concepts of adding layouts to the routing system. These will remain constant on routing and will not change. This earlier required many different hacks to perfect and as someone who has felt the pain of implementing these, love that these are making their way in natively.

### [Introducing Whisper - OpenAI](https://openai.com/blog/whisper/)

> We’ve trained and are open-sourcing a neural net called Whisper that approaches human level robustness and accuracy on English speech recognition.

It's bloody perfect.

### [Introducing Make-A-Video - Meta](https://ai.facebook.com/blog/generative-ai-text-to-video/)

Everyone hypothesised an AI that would created videos from description when they saw Dall-E come up. But no one would have thought it would be this fast. Meta has released their private Beta for Make-a-Video, an AI tool that does just that.

Also, Dall-E is now [available without waitlist](https://openai.com/blog/dall-e-now-available-without-waitlist/)

### [Introducing Signals - PreactJS](https://preactjs.com/blog/introducing-signals/)

Signals are the new state management library from PreactJS. If you have used the modern ones like Zustand or Recoil, this would be very familiar. The library like all of Preact, comes with a lean philosophy of 1.6kB. They can be used inside or outside your components unlike Hooks and can be used with React or PreactJS.

## Tutorials

### [What’s New With Forms in 2022? - CSS Tricks](https://css-tricks.com/whats-new-with-forms-in-2022/)

There are things that show up on browsers every month and some of it gets drowned in the content. Ollie Williams makes of list of features that makes forms better.

- `requestSubmit` allows you to submit a form programmatically and validate the form at the same time.
- `inert` attribute to disable an entire form and make it non focusable.

### [Creative List Styling - web.dev](https://web.dev/creative-list-styling/)

Most people forget things are lists. This article lists down different ways in which lists and numbering can change designs and how adaptable they are. `counter` is a pretty amazing CSS property to have.

### [Use the Right Container Query Syntax - Miriam Suzzane](https://www.oddbird.net/2022/08/18/cq-syntax/)

Since Safari has now shipped Container Query units, might as well study about them. The units are cqw, cqh, cqi, cqb, cqmin and cqmax. Confused much?
