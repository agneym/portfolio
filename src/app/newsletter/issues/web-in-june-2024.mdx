## In the Spotlight 🔦

The ECMA General Assembly approved ECMAScript 2024 and we have a new standard for browsers to work toward.

Some of my favourite features coming listed in no particular order.

### Promise.withResolvers

The normal way of creating a promise is with Promise constructor.

```javascript
new Promise(
  (resolve, reject) => { ··· }
);
```

But this limits the usage of `resolve` and `reject` functions to the callback function, adding a level of nesting. Instead `withResolvers` gives you resolvers right off the gate.

```javascript
const { promise, resolve, reject } = Promise.withResolvers();
```

### /v flag for regular expression matching

The new `/v` flag is used for unicode regular expression matching and promises and upgrade over the currently used `/u` flag.

Exploring JS notes:

> **Use flag /v whenever you can**
> This flag improves many aspects of JavaScript’s regular expressions and should be used by default. If you can’t use it yet because it’s still too new, you can use /u, instead.

- [ECMA Standard Definition](https://ecma-international.org/publications-and-standards/standards/ecma-262/)
- [Ecma International approves ECMAScript 2024: What’s new?](https://2ality.com/2024/06/ecmascript-2024.html)

---

Something else I'm excited about is the Set methods coming to baseline this month. You can now use `union`, `intersection` etc. across browsers.

```javascript
const odds = new Set([1, 3, 5, 7, 9]);
const squares = new Set([1, 4, 9]);
console.log(odds.intersection(squares)); // Set(2) { 1, 9 }
```

- [Set MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Set)
- [Set methods are part of baseline](https://web.dev/blog/set-methods)
