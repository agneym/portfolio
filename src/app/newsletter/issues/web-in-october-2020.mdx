Another month and another large company goes fully remote - [Dropbox](https://www.businessinsider.in/tech/news/dropbox-will-let-all-employees-work-from-home-permanently-as-it-turns-its-offices-into-wework-like-collaborative-spaces/articleshow/78650656.cms). Github received a [takedown notice](https://github.com/github/dmca/blob/master/2020/10/2020-10-23-RIAA.md) for the very popular cli - youtube-dl from RIAA. The cause seen here is that it can be used for downloading copyrighted songs from Youtube. This stirred up a controversy on whether DMCA was being misused against software which has lots of other lawful use cases. Here's the [XDA guide](https://www.xda-developers.com/youtube-dl-riaa-dmca/) to find out more.

# Releases

- [NextJS 10](https://nextjs.org/blog/next-10) - This is the release I'm most excited about. This is one feature that NextJS was missing from Gatsby (as a plugin, but it was always installed, so does it matter). This release should get lots of people to switch over.
- [NodeJS 15](https://nodejs.medium.com/node-js-v15-0-0-is-here-deb00750f278) - The new NodeJS release brings some awaited features like `AbortController` to abort your Promises. NodeJS also ships in with NPM 7 with support for Workspaces, which has been delayed due to different controversies under NPM, but now we can finally move over from Yarn 1.
- [Webpack 5](https://webpack.js.org/blog/2020-10-10-webpack-5-release/) - Webpack is bringing this out of beta after so long (which is expected for a project that is depended on by so many projects). While there aren't major changes, the performance enhancements are known to be worth it.
- [Skypack Discover](https://www.skypack.dev/blog/2020/10/introducing-skypack-discover/) - Fred K. Schott, who wrote Snowpack is bringing a new open source discovery tool named Skypack. It also brings package ratings with improvement notes that package owners can use for better more consistent library solutions.
- [AVIF](https://twitter.com/smashingmag/status/1319564497011486721) - A new image format is here and as always the answer to when you can use it is _It depends_. More to work on for cloud and terminal based image compression libraries.
- [Remix Framework](https://remix.run/features) - Remix is a new paid React framework from the creators of React Router and they have just released an early look. There is an ongoing debate in whether people would pay for such a framework when NextJS or GatsbyJS is available for free.

# Tutorials

- [Why I love React](https://epicreact.dev/why-i-love-react/) - In a JavaScript world that was throwing away libraries and technologies in days, React managed to come in and stick on for years now. What makes React tick? Kent C Dodds tries to explain in this blog post.
- [Serverless Horror Stories](https://thenewstack.io/serverless-horror-stories/) - It's pretty clear that we can't just move things to serverless and save money from it. Need proof? This article is full of those horror stories.
- [GraphQL at Treebo](https://tech.treebo.com/graphql-at-treebo-f5b41c22c06f) - Treebo discusses their microservice architecture and how GraphQL has helped smoothen the communication process.

# In the Spotlight

[XState](https://xstate.js.org/) has been a state management library that is gaining momentum in the JavaScript community. The idea is to use state charts where state can be easily visualised, also it helps to ensure that it never reaches an impossible state.

This month we saw:

- The [new issue of ThoughtWorks Radar](https://www.thoughtworks.com/radar/languages-and-frameworks?blipid=202005067) has moved XState from "access" to "trail"
- [How xstate saved our 🥓](https://dev.to/egghead/how-xstate-saved-our-3bhg) - XState has been slowly gaining momentum as a state solution in JavaScript apps. Here [egghead.io](https://egghead.io/) founder discusses how they are using XState for their platform.
- [Refactoring useReducer to XState](https://swizec.com/blog/refactoring-a-usereducer-to-xstate-pt1-codewithswiz-11) - Swizec Teller comes has a live coding session refactoring `useReducer` to XState and how it's better.
- [Choosing your own adventure - NextJS Conf](https://www.youtube.com/watch?v=_qkoAPRG2wY) - At one of the most anticipated talks at NextConf, Cassidy Williams demoed the code for a text adventure game using XState - fully visualised state of course.

If you like to catch up, David K, author of XState is doing a [live workshop for State Machines on FrontendMasters](https://frontendmasters.com/workshops/xstate-react/) starting November 5th.

# In Other News

- [Managing a pandemic on Excel](https://www.thelondoneconomic.com/politics/shock-and-despair-follow-revelations-that-world-beating-test-and-trace-system-is-being-run-on-excel/05/10/) - It's said that every business application moves towards Excel everyday it is build. But Britain gave the world a shock as the news of reaching the limit of Excel and missing Coronavirus patients came out. _Surely, it can't have reached 1,048,576 rows_, they said, but they had arranged cases per column - so that was just 16,384 aka _XFD_.
- [Among Us Hacks](https://kotaku.com/among-us-has-a-cheating-problem-1845256959) - Among Us has caught our attention this month with [politicians making records out of it](https://www.theguardian.com/games/2020/oct/22/alexandria-ocasio-cortez-ilhan-omar-among-us-twitch-stream-aoc). But as with Fall Guys last month, there have been hackers throwing the system out of balance and developers rushing to fix them.
- [How URL was build](https://www.welcometothejungle.com/en/articles/btc-url-internet) - In an era where Google is trying to hide URLs wherever possible, this is a great look into one of the most recognisable identifiers of World Wide Web.
- [How Bitcoin powered Nigerian protests](https://qz.com/africa/1922466/how-bitcoin-powered-nigerias-endsars-protests/) - I have been a proponent of the theory that blockchain is a solution to no real world problem, but it's heartening to see bitcoin helping these rebellions and not just as drug money.
