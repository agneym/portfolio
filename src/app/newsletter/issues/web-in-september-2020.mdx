October is here and so is [Hacktoberfest](https://hacktoberfest.digitalocean.com/)!

In it's 7th year, Hacktoberbest is one of the most recognised open source celebratory events all time. If you are looking to participate for the first time, here are the basics:

> To earn your Hacktoberfest tee or tree reward, you must register and make four valid pull requests (PRs) between October 1-31 (in any time zone). PRs can be made to any public repo on GitHub, not only the ones with issues labeled Hacktoberfest.

Make sure to checkout their site for [more details](https://hacktoberfest.digitalocean.com/).

_Fast Refresh for React_

If you work on React, checkout the new Fast Refresh that's coming to all your favorite boilerplates. It's the advanced version of hot loader, works much better and preserves state. Takes [just three steps to setup](https://github.com/pmmmwh/react-refresh-webpack-plugin).

# Releases

We sat through a [Google Pixel 5 launch event](https://www.youtube.com/watch?v=EaBXd-96uNg) this week. But other than the flagships, few other phones caught my eye this month.

- [Surface Duo](https://www.microsoft.com/en-us/surface/devices/surface-duo) - Two screens but can both closing inwards.
- [LG Wing](https://www.lg.com/global/lgwing) - Two screen opening like a T
- [Lenovo Thinkpad X1 Fold](https://www.lenovo.com/in/en/thinkpad-x1-fold) - First foldable Tablet.
- [ZTE Axon 5G](https://www.xda-developers.com/zte-axon-20-5g-china-launch-first-smartphone-under-display-camera/) - First smartphone with under display camera.

I'm not going to be buying any of these anytime soon and neither should you. But we have seen this bland square boxes for so long, it's nice to see some innovation.

- [Vue 3.0](https://github.com/vuejs/vue-next/releases/tag/v3.0.0) - The new Vue release by the anime name One Piece is out and it brings Hooks. Vue docs is one of the best in business and with this release, it's redesigned to be better.
- [Postgres 13](https://www.postgresql.org/about/news/postgresql-13-released-2077/) - Postgres has a setup that shouldn't work, no company at it's helm, run by community and yet it outperforms every other competitor out there. [Lessons learned from running Postgres 13](https://pganalyze.com/blog/postgres13-better-performance-monitoring-usability) lists some tips and feature lists from running the new version in production.
- [New JSX transform](https://reactjs.org/blog/2020/09/22/introducing-the-new-jsx-transform.html) - This comes with React 17 and now we don't have to import React to every component anymore. (NextJS users are scratching their heads wondering what this is)
- [Tables by Google](https://tables.area120.google.com/about#/) - Every month now, I report on a Airtable clone, after [Amazon](https://www.honeycode.aws/) and [Microsoft](https://www.microsoft.com/en-us/microsoft-365/microsoft-lists), here's Google. No Code for the win.
- [Youtube Shorts](https://techcrunch.com/2020/09/14/youtube-launches-its-tiktok-rival-youtube-shorts-initially-in-india/) - Everyone wants a piece of TikTok Magic 🎩. Tik Tok meanwhile attempting to avoid the US ban, gave us a look into what they want with their [recommendation algorithm](https://www.axios.com/inside-tiktoks-killer-algorithm-52454fb2-6bab-405d-a407-31954ac1cf16.html).
