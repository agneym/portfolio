## Releases

- [Browser Functions: A new serverless platform using Web Browser execution engines](https://dev.to/richardyoung00/browser-functions-a-new-serverless-platform-using-web-browser-execution-engines-fk5) - IBM had a crazy idea that they could execute serverless functions in a browser instead of a container. And the best part is: It's faster.
- [Yarn 2](https://dev.to/arcanis/introducing-yarn-2-4eh1) - just came out with PnP as the default and people are not very [happy about it](https://github.com/yarnpkg/berry/issues/766). It differs from npm so much that developers are worried they have two write two different Getting Started now.
- [Puppeteer 2](https://github.com/puppeteer/puppeteer/releases/tag/v2.1.0) - The crowd favorite puppeteer is now v2 and supports firefox binaries. Might be a step in desperation as Microsoft's [Playwright](https://github.com/microsoft/playwright) gains in popularity.
- [Styled Components v5](https://medium.com/styled-components/announcing-styled-components-v5-beast-mode-389747abd987) - _CSS-in-JS is a hill I'm willing to die on_ and my favorite library for it is on v5 now slimmer, faster and no breaking changes.

### My Content

- [JAMStack Reader app](https://blog.agney.dev/netlify-fns-cra/) - Created a serverless reader app with React, Netlify Functions and wrote about it.
- [My Blog has RSS](https://blog.agney.dev/rss.xml) - You can subscribe to my blog from RSS now. [Here is a blog post](https://blog.agney.dev/Add-RSS-feed-to-mdx/) with procedure.

## Tutorials

- [Clean Code - JavaScript](https://github.com/ryanmcdermott/clean-code-javascript) - After Dan Abramov's [article on clean code](https://overreacted.io/goodbye-clean-code/) took off, huge amount of twitter discussions have lead to the resurgence of this github repo and boy! it is a gem.
- [Simple state machine library in JavaScript](https://kentcdodds.com/blog/implementing-a-simple-state-machine-library-in-javascript) - State Machines and associated libraries (in particular [XStateJS](https://xstate.js.org/)) have been gathering a lot of hype on the frontend. Kent C Dodds wrote about creating one yourself in JavaScript. Worth a read for the concepts.
- [CSS Cascade](https://wattenberger.com/blog/css-cascade) - Amelia Wattenberger writes this beautiful blog explaining CSS cascade with illustrations.
- [An OS on React Native](https://medium.com/sanctuary-computer-inc/building-lightos-with-react-native-4b6e4ad1cd7f) - Well, it's true. LightOS is being build on React Native. React Native is going places.
- [React Native as default at Shopify](https://engineering.shopify.com/blogs/engineering/react-native-future-mobile-shopify) - With AirBnB bailing on React Native, there was a gap of large enterprise backers and with recent [debugging improvements](https://twitter.com/dabit3/status/1220271520091602945) and others, they have managed to bring Shopify to the party.

## In Other News

- [Remote Work at FYI](https://share.transistor.fm/s/8f09d4fb) - Marie Prokopets breaks down the results from a survey of remote workers that she and her cofounder Hiten Shah had conducted. The results are sometimes astonishing with tips being _just walk out of the room and walk back in to get the office feeling_. Definitely can try that out.
- [Your New Year Resolution has already failed](https://www.youtube.com/watch?v=NVGuFdX5guE) - CGP Grey on his youtube channel makes a hypothesis that themes and not resolutions are the way to better habits. On every juncture visualise your overarching theme for the year and act accordingly. Also, they have to be broad (which is interesting if you have read [Atomic Habits](https://jamesclear.com/atomic-habits))
