Hello 2022 👋🏻

2021 was an year when restrictions that were placed in the previous year got relaxed. It is great to see that some of the ideas that were generated in the time of forced restrictions are continuing to be used. It's a lot like building web for accessibility, when you are building for special cases you are making the web better for everyone. It's the same with building for remote use cases, you make the world a lot more accessible.

## Releases

- [Safari Technology Preview 137](https://webkit.org/blog/12156/release-notes-for-safari-technology-preview-137/) - This release is special because it brings a CSS feature (Safari first!), `:has`. It's a the first CSS selector to select the parent which has a child.
- [WebAssembly and Back Again](https://hacks.mozilla.org/2021/12/webassembly-and-back-again-fine-grained-sandboxing-in-firefox-95/) - Firefox 95 now uses a new technique named RLBox to convert specific areas of code into Web Assembly. This way malicious actors will have one extra step to escape the sandbox created by browsers.
- [Open Props](https://open-props.style/) - It's like Tailwind but with only CSS variables. A token based CSS system where variables are prefilled.
- [Framer Motion 3D](https://www.framer.com/docs/three-introduction/) - The excellent Framer Motion library has a 3D version now based on Three Fiber.
- [patterns.dev](https://www.patterns.dev/) - An ebook from the wonderful Addy Osmani and Lydia Hallie on architecting web applications.

## Tutorials

- [Coding Interview with Dan Abramov](https://youtu.be/XEt09iK8IXs) - Watch Dan Abramov take a coding interview with Bed Awad, he breezes through some questions and struggles on others (centering a div)
- [DNS "propagation" is actually caches expiring](https://jvns.ca/blog/2021/12/06/dns-doesn-t-propagate/) - It takes time for the DNS propagate is something we say every day. Julia Evans debugs this in the most epic way possible. [Mess with DNS](https://messwithdns.net/)
- [Defensive CSS](https://ishadeed.com/article/defensive-css/) - CSS is often written as copied from a design tool, or the content currently available. When the content is dynamic or changes (which is very often), the CSS breaks. This article introduces some defensive CSS properties that you can use to counter the same.
- [Designcember](https://designcember.com/) - web.dev has added an article each for every day of December, it's a site that's very easy on the eyes even if you don't read any of the articles.
- [Designing Better Links For Websites And Emails: A Guideline](https://www.smashingmagazine.com/2021/12/designing-better-links-websites-emails-guideline/) - A very detailed take on how to write links. A lot of people write links as - _Here_, _This_, _Click Here_, but how to write them well? Are the links here correct? Find out in the article.

### React Conf

- [Concurrent Features](https://reactjs.org/blog/2021/12/17/react-conf-2021-recap.html) - React 18 is finally shipping with concurrent features (and not a concurrent mode). The features are completely opt in and there aren't any breaking changes.

- If you want to try out the new React 18 RC, you can check out Shruti Kapoor's video for some step by step instructions:

[https://youtu.be/ytudH8je5ko](https://youtu.be/ytudH8je5ko)

- [Web Components RFC](https://github.com/facebook/react/issues/11347) - It has been a complaint since forever that React does not respect Web standards. The components RFC is here and it aims to fix this pain point.

- [React without Memo](https://www.youtube.com/watch?v=lGEMwh32soc) - One of the most interesting takes from the conference was this talk from Xuan Huang on common pitfalls with `memo` and what the team intends to do about it.
